# Smart Study Planner

Smart Study Planner is a Python-based application designed to help students organize their studies and manage their exam preparation.

## Features

- Add subjects
- Set exam dates
- Set subject difficulty
- Set required study hours
- Track study progress
- Calculate study priority
- Generate a smart study timetable
- Store data using SQLite

## Technologies Used

- Python
- Tkinter / ttk
- SQLite
- VS Code

## How to Run

Open the project in VS Code and run:

```bash
python app.py
